# LeetCode Journey

A growing collection of my LeetCode solutions, documenting my progress in **Data Structures & Algorithms (DSA)** and problem-solving.

The repository is automatically updated as I solve and submit problems on LeetCode.

---

## About

**LeetCode Journey** is a personal, open-source collection of solutions to LeetCode problems.

The goal is to:

* Practice and strengthen DSA fundamentals
* Improve algorithmic problem-solving
* Explore different approaches to coding problems
* Maintain a searchable reference of solved problems
* Track my progress over time

Solutions are primarily written with an emphasis on **clarity, efficiency, and readability**.
